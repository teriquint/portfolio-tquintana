# Local Favorites Tracker

This is a web app that lets users keep track of their favorite local places. Users can add places, give them a rating, add notes, search, filter by category, and delete favorites.

## Built With

- HTML
- CSS
- JavaScript
- localStorage

I used localStorage so the favorites stay saved even after the page is refreshed.
