# Task Tracker Project Status

## Where I Am

The main parts of my Task Tracker are working and mostly complete. I started with a basic task tracker, but as I tested it I made changes that made the app more useful and easier to organize. It was helpful to test it and see what was working and what was still needed. I am now doing the final testing, cleaning up the design and style, and finishing the documentation for the project.

## What Is Working

- Users can create a project and add a project due date
- Active projects appear in a dropdown when adding a task
- Users can add tasks, due dates, and optional details
- Tasks are grouped under the project they belong to
- Projects are organized by month
- Tasks show as Past Due, Due Today, In Process, or Completed
- Past due tasks move to the top
- In process tasks stay in the middle
- Completed tasks move to the bottom
- Users can open and close task details
- Users can mark a task complete or incomplete
- Users can delete tasks
- Users can mark an entire project complete
- Completed projects collapse so the tasks are hidden
- Completed projects are removed from the active project dropdown
- Completed projects can be reopened
- Users can add optional notes to a completed project
- Projects and tasks are saved with localStorage
- The app is working on GitHub Pages
- The layout adjusts for smaller screens

## What I Am Still Working On

I need to finish my project documentation, reflection, and prepare for the walkthrough as well as continue to use the tracker app to see if there are any areas that need refinement.

## What Changed From My Original Plan

My original idea was much more basic. I planned to add a project name, task, and deadline and then display the tasks by status. However, as I worked on the project, I realized I did not want to enter the same project name and project due date every time I added a task. I changed the app so a project is created once and then selected from a dropdown when adding tasks. This was an idea that I took from our favorites tracker which made organization easier and helped to eliminate misspellings. I also added task details, project completion, project notes, and automatic task organization because those features made the tracker more useful. Color coding was something that I did not consider until I started using the app and found it necessary to have a quick visual of where the task was.

## If I Had More Time

If I had more time, I would like to add a dashboard where I could see all of my open and upcoming projects in one place. I could see the app becoming two pages, with the dashboard as the main page and a button that opens the Task Tracker when I need to add or update projects and tasks. I would also like to add an option to export completed projects to Excel so they could be archived by year. I think that would be helpful for keeping a record of completed projects without leaving everything in the active tracker.
