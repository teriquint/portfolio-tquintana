# Task Tracker

Task Tracker is a web application I created for Project Zed in WRIT 40363. I wanted to create something that could help me keep track of multiple projects/events, tasks, and deadlines all in one place. I am always looking for better ways to organize my daily work.

## MVP

In my app you can do the following:

- Add a project and project due date
- Add tasks to an active project
- Add a task due date
- Add optional details to a task
- See if a task is past due, due today, or in process
- Mark a task complete
- Delete a task
- Mark a project complete
- Keep projects and tasks saved after refreshing the page

## New Technique

My new technique was using JavaScript dates to compare and organize deadlines. I used dates to determine if a task is past due, due today, or still in process. I also used the dates to help organize the projects and tasks by deadline and color code so I could see visually where I was at.
