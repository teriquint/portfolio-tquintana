Project Zed: Task Tracker

I created a Task Tracker to help organize multiple projects, tasks, and deadlines. Users can create projects, add tasks and details, track deadline status, complete projects, and keep their information saved between visits.

My new technique for this project was using JavaScript dates to compare deadlines and automatically organize tasks as Past Due, Due Today, In Process, or Completed.
