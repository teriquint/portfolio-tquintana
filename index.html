WRIT 40363 Projects

These four projects show my progression through WRIT 40363, from building my first portfolio to creating interactive JavaScript applications.

  • Project 1: Personal Portfolio

    My first project was a responsive personal portfolio built with HTML and CSS. It gave me a place to practice semantic HTML, responsive layouts, accessibility, and organizing information for an online audience.

    This original version also became the starting point for the revised portfolio I created at the end of the course.

    Technologies: HTML, CSS, Flexbox, Grid, GitHub Pages

    View Original Portfolio

  • Project 2: Local Favorites Tracker

    I created a web app for saving and organizing favorite local places. Users can add favorites, search and filter them, delete places, and keep their information after refreshing the page.

    This project helped me become more comfortable working with JavaScript, arrays, forms, DOM manipulation, and localStorage.

    Technologies: HTML, CSS, JavaScript, localStorage

    View Local Favorites Tracker

  • Project 3: Personal Data Dashboard

    I built a personal data dashboard that combines several small widgets into one page. It includes weather data, daily quotes, and a light and dark theme that saves the user's preference.

    This project gave me more experience working with JavaScript, JSON, Fetch, and creating an interface that presents different kinds of information clearly.

    Technologies: HTML, CSS, JavaScript, JSON, Fetch API, localStorage

    View Personal Data Dashboard

  • Project Zed: Task Tracker

    I created a Task Tracker to help organize multiple projects, tasks, and deadlines. Users can create projects, add tasks and details, track deadline status, complete projects, and keep their information saved between visits.

    My new technique for this project was using JavaScript dates to compare deadlines and automatically organize tasks as Past Due, Due Today, In Process, or Completed.

    Technologies: HTML, CSS, JavaScript, Date objects, localStorage

    View Task Tracker
